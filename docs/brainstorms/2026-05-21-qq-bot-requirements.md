# QQ 多功能 Bot

## Summary

一个混合型 QQ bot，以被动响应为主（@ 提及和指令触发），搭配少量可配置的主动行为。核心功能为知识库优先 + LLM 兜底的智能问答；扩展功能包括 B站 BV 号自动识别解析（视频信息 + AI 摘要）和基于累积聊天数据的群友画像（发言统计、兴趣标签、关系网络）。

---

## Problem Frame

目前群内已有简单的关键词匹配 bot，但匹配逻辑过于僵硬——问法稍微变化就无法命中，体验很差。用户希望有一个真正「懂人话」的 bot：能理解自然语言提问、在知识库无匹配时用 LLM 兜底回答，同时提供一些群内高频场景的自动化能力（识别 B站链接/视频号、了解群友画像）。这些都是现有关键词 bot 完全无法覆盖的空白。

---

## Actors

- A1. **群友 (Group member)**: 在群内通过 @bot 提问或发消息触发 bot 功能，消费 bot 返回的信息
- A2. **bot 主人 (Bot owner)**: 配置知识库、管理主动行为开关、调整 bot 人设参数

---

## Key Flows

- F1. **智能问答**
  - **Trigger:** 群友 @bot 并附带问题
  - **Actors:** A1, A2
  - **Steps:** 群友发送 @bot + 问题 → bot 解析问题意图 → 优先匹配知识库 → 匹配成功则返回预设回答 → 匹配失败则调用 LLM 生成回答 → 返回结果
  - **Outcome:** 群友获得问题答案
  - **Covered by:** R1, R2, R3

- F2. **B站 BV 号解析**
  - **Trigger:** 群内消息中出现 B站 BV 号（无需 @bot）
  - **Actors:** A1
  - **Steps:** 群友发送含 BV 号的消息 → bot 自动识别并提取 BV 号 → 调用 B站 API 获取视频信息 → 回复视频信息卡片 → 可选生成 AI 摘要
  - **Outcome:** 群内直接看到视频信息和摘要，无需离开 QQ 去 B站查看
  - **Covered by:** R4, R5, R6

- F3. **每日群聊总结**
  - **Trigger:** 每日定时触发（如每晚 22:00），无需群友互动
  - **Actors:** A2
  - **Steps:** 定时器到期 → bot 汇总当日群聊数据 → 生成总结：当日热门话题关键词、发言活跃榜、新人/潜水提醒 → 发送至群内
  - **Outcome:** 群内收到当天的群聊回顾
  - **Covered by:** R7, R13

- F4. **群友画像查询**
  - **Trigger:** 群友 @bot 并请求查看某人画像（如 "@bot 看看XXX的数据"）
  - **Actors:** A1
  - **Steps:** 群友 @bot 发起画像请求 → bot 从累积数据中检索目标用户统计 → 生成发言统计 + 兴趣标签 + 关系概览 → 返回格式化的画像报告
  - **Outcome:** 群友获得目标用户的群内行为画像
  - **Covered by:** R8, R10, R11, R12

---

## Requirements

**智能问答**
- R1. bot 被 @ 提及时，提取问题文本，先在知识库中做语义/关键词匹配，匹配命中则返回预设回答
- R2. 知识库无匹配时，将问题发送至 LLM 生成回答，回答携带简短免责（如 "AI 生成，仅供参考"）
- R3. 知识库支持主人 (A2) 通过指令添加、修改、删除、列出 Q&A 条目

**B站解析**
- R4. bot 自动检测群消息中的 Bilibili BV 号，无需 @bot 即可触发
- R5. 识别后回复视频信息卡片，包含：标题、UP 主、播放量、封面图、视频时长
- R6. 支持通过指令请求该视频的 AI 内容摘要（如 "@bot 总结一下这个视频"）

**群友画像**
- R7. bot 持续记录群内消息，按用户维度统计：总发言数、活跃时段分布、高频词汇
- R8. 基于聊天内容自动推断群友兴趣标签（如游戏、动漫、编程等），支持人工修正
- R9. 分析群友间的互动关系：@ 频率、互相回复次数，构建简化的关系强度图
- R10. 支持按指令查询指定群友的画像报告，报告包含 R7-R9 的数据
- R11. 画像数据仅来源于该群内的公开聊天，不爬取群友其他平台信息

**行为模式**
- R12. bot 有两种默认主动行为：BV 号自动识别（始终开启）和每日群聊总结（默认开启，可关闭）
- R13. 每日群聊总结内容包含：当日热门话题关键词 TOP 5、发言活跃榜、新人/潜水提醒
- R14. 除 R12 所列之外的可选主动行为均为独立开关，默认关闭，由 A2 手动启用
- R15. bot 具有可配置的基础人设（称呼风格、回复语气），由 A2 通过配置文件设定

## Acceptance Examples

- AE1. **Covers R1, R2.** 群友在群内发送 "@bot 群规是什么"，bot 在知识库中匹配到"群规"条目，直接返回预设的群规文本，不调用 LLM
- AE2. **Covers R1, R2.** 群友发送 "@bot Python 的 GIL 是什么意思"，知识库无匹配，bot 调用 LLM 生成解释，回复末尾附带 "AI 生成，仅供参考"
- AE3. **Covers R4, R5.** 群友发送 "这个视频 BV1xx411c7mD 好搞笑"，bot 检测到 BV 号，自动回复视频标题、UP 主、播放量和封面图
- AE4. **Covers R1.** 群友在群内正常聊天发送 "有人知道群规在哪看吗"，未 @bot，bot 不响应（即使知识库有匹配）
- AE5. **Covers R10.** 群友发送 "@bot 看看小明的画像"，bot 返回小明在群内的发言统计、推断的兴趣标签、以及与小明的互动关系网络摘要
- AE6. **Covers R12, R13.** 每晚 22:00，bot 自动发送当日群聊总结："今日热词：原神、新版本、抽卡 | 发言 TOP3：小明(42条)、小红(35条)、小刚(28条) | 潜水提醒：大白今天还没说话哦"

## Success Criteria

- 同一个意图用不同问法提问（如 "群规是什么" / "群里有啥规矩" / "rules"），bot 均能命中知识库
- BV 号出现在消息中时，bot 在 5 秒内回复视频信息卡片
- 群友画像经过一周积累后，生成的兴趣标签至少有 60% 被认为准确（定性评估）
- 每日群聊总结按时自动发送，内容覆盖当天实际讨论的热点话题
- bot 不会在未 @、未触发 BV 检测、非定时总结时段主动发言，避免刷屏

---

## Scope Boundaries

- 不包含 Web 管理后台 —— 配置通过文本指令或配置文件完成
- 不包含多群数据隔离 —— v1 仅服务 1-2 个群，按群 ID 区分即可，无需管理面板
- 不包含 B站内容订阅追踪（UP 主动态、番剧更新提醒等）—— 仅做单视频解析
- 不含群友画像的导出和可视化图表 —— 纯文本报告即可
- 不含全自动 AI 主动插话 —— 被动为主路线，主动行为限定在可配置的有限场景

---

## Key Decisions

- **知识库 + LLM 混合而非纯 LLM**: 纯 LLM 成本高且对固定问题（群规、FAQ）过度生成；知识库优先保证常见问题快速准确，LLM 兜底覆盖长尾
- **被动为主而非主动对话**: 小群场景下主动插话容易招烦，且增加 LLM 调用成本；仅 BV 识别作为默认主动行为是因为它无需理解上下文即可触发
- **画像依赖自然数据积累而非主动采集**: 不用问卷或强制互动收集画像数据，仅靠日常聊天自然沉淀，降低群友抵触感

---

## Dependencies / Assumptions

- 依赖 QQ bot 框架/协议可正常收发群消息（如 Mirai、go-cqhttp 或官方 API）
- 依赖 B站 API 可公开获取视频元数据（标题、UP 主、播放量等）
- 依赖 LLM API（如 OpenAI / Claude / 本地模型）可用且 owner 持有有效 API key
- 假设 bot 所在群的聊天频率足够画像功能在合理时间内积累有效数据
